① 사이트 설정

Netlify 배포 후 실제 주소를 입력하세요. canonical · sitemap · RSS에 자동 반영됩니다.

② 빠른 포스팅 도우미

핵심 정보만 입력하면 제목·slug·검색설명·AI 핵심답변·본문 초안·FAQ를 자동으로 채웁니다. 생성 후 원하는 부분만 고쳐서 발행하세요.

이제 직접 타이핑할 필요 없이 위 항목을 선택하고 「포스팅 초안 자동 채우기」만 누르면 됩니다.
