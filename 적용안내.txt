WAWA v13.5.4 관리자 포스팅 동기화·중복 제거 패치

현재 사이트의 다른 기능과 관리자에서 작성한 실제 포스팅은 그대로 유지하는 안전 패치입니다.
이 ZIP 안의 build.js 와 content/posts.json 만 현재 프로젝트에 덮어쓰세요.
중요: content/posts/ 폴더는 삭제하거나 교체하지 마세요. 관리자에서 작성한 실제 포스팅이 들어 있습니다.

수정 내용
1. 사이트는 관리자 CMS가 관리하는 content/posts/*.json만 게시글 원본으로 사용합니다.
2. 구버전 content/posts.json 샘플 글은 더 이상 읽지 않습니다.
3. 교육정보 목록은 매 빌드마다 완전히 새로 만들어 예전 카드가 HTML에 누적되지 않습니다.
4. CMS에서 삭제한 글의 예전 posts/*.html도 빌드 때 자동 삭제합니다.
5. 메인 최신 교육정보 / 교육정보 전체 목록 / 상세페이지 / sitemap / RSS가 모두 같은 관리자 글 목록을 기준으로 생성됩니다.
