WAWA v11 발행/예약 기능

1) 기존 기능 유지: 선택형 초안, 이미지, 썸네일, 사이트 폴더 저장, 파일 다운로드, 임시저장.
2) 즉시 발행: 관리자에서 '지금 발행 파일 반영'을 눌러 Git/Netlify 사이트 폴더에 파일을 반영합니다. Git 저장소를 사용하는 경우 변경 파일을 push하면 Netlify가 배포합니다.
3) 예약 발행: 날짜/시간을 지정해 관리자 브라우저에 예약합니다. 정적 HTML만으로는 브라우저가 닫힌 상태에서 Git/Netlify에 자동 push할 권한이 없으므로, 예약 시간이 지나 관리자 페이지를 열면 발행 대상 글을 알려주고 불러옵니다.
4) 완전 무인 예약 발행은 GitHub 저장소/Netlify API 연결(인증)이 추가로 필요합니다. 인증키를 HTML에 직접 넣으면 노출되므로 포함하지 않았습니다.
